# Architecture

This directory contains documentation describing the current architecture of AMPERSAND.

Use it for documentation about how the system is structured and how its major components interact, including:

- application architecture;
- database and data model;
- authentication and authorization;
- project and user architecture;
- frontend/backend boundaries;
- integrations and external services;
- AI and retrieval architecture when these are introduced;
- diagrams and system-level technical documentation.

Architecture documents should describe the **current intended state of the system**, not merely record historical discussions.

When implementation materially changes the architecture, check whether the relevant documentation here should also be updated.

Do not create documentation for speculative future architecture unless it is useful to an active design decision.
